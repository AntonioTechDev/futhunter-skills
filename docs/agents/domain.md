# Domain docs

This is a single-context repository.

Before exploring or modifying the repository, read `CONTEXT.md` when present and any relevant ADR under `docs/adr/`.

Missing domain documents are not an error: continue silently. Create or update them only when domain terminology or architectural decisions need to be recorded.

Use the vocabulary defined in `CONTEXT.md` in skills, scripts, issues and tests. Surface any conflict with an existing ADR explicitly.
