# Issue tracker: GitHub

Issues and specifications for this repository live in GitHub Issues.

## Operations

- Infer the repository from `git remote -v`.
- Create one GitHub issue for each approved ticket.
- Read the issue body, comments and labels before working on it.
- Use GitHub native dependencies to represent blockers when available.
- Otherwise add `Blocked by: #<number>` at the beginning of the issue.
- Apply `ready-for-agent` only when the ticket is complete, verifiable and unblocked.
- Pull requests are not part of the triage queue.

When a skill says “publish to the issue tracker”, create a GitHub issue in this repository.
